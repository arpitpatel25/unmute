How to use Unmute

Speak into the app in front of you, start a session for real work, or ask the Unmute Agent to manage work across sessions.

DictationWrites where your cursor is.
SessionDoes one task with you.
Unmute AgentFinds and manages sessions.
Dictation Sessions Notetaker Notch

Dictation

Say it once and Unmute types it into the app under your cursor.

Talk where you type

Your current Dictation key is Fn.

Tap Fn to start. Tap Fn again to finish.

Click a message box, then say “Can we meet tomorrow morning?”

Add context

Show Unmute what “this” means while you talk.

Copy text, a link, a file, or an image while Dictation is listening. Screenshots work too: ⌘ ⇧ 3 full screen, ⌘ ⇧ 4 region.

Say “Explain this error,” copy the error, then keep talking.

Use Scratchpad

Keep several pieces together before sending.

Collect dictation, copied material, and screenshots in Scratchpad, then send the whole request to a session.

Sessions

A session does the work. The Unmute Agent is the session manager.

Start one directly

Best when you already know the task.

Tap Right Option to start. Tap it again to send.

“Open the checkout code and fix the failing test.”

Ask the Unmute Agent

Use it when the right session or next step is unclear.

Double-tap Right Command to start. Tap Right Command once to send.

“Find the checkout session, resume it, and give it today’s meeting notes.”

Open the session pocket

Glance at active sessions without leaving your app.

Hold Right Command first then press Right Option. Press the same combination again to expand.

  • ← → move
  • Return open
  • Esc shrink

Notetaker

Keep a meeting transcript, notes, and useful screenshots together.

Start or stop notes

Works while you stay in the meeting app.

Double-tap Left Control to start. Double-tap it again to stop.

Save what is on screen

The image stays beside that meeting.

Double-tap Left Command for the full screen. Hold it for about 600 ms to choose a region.

Capture the roadmap slide so it stays with the transcript.

Inside the notch

The notch keeps your current sessions close while you work elsewhere.

Move or close

The nearest open layer closes first.

← → moves between sessions. Return opens one. Esc closes a menu first, then shrinks the surface.
