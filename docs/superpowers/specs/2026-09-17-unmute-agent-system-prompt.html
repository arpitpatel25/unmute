How it is assembled

Two pieces of text are joined, written to a file, and handed to the model once — each time a fresh Agent session starts (a new conversation, a provider switch, or a restart). The model then has it on every turn of that session.

Does it have sections?

No. It is one flat list of 47 paragraphs with no headings. Rules, procedures, tool guidance and reply formats sit side by side, and the same theme turns up in several places.

What is in it

The same 47 paragraphs regrouped by theme. “Kind” is what the paragraph mainly does: a rule constrains, a procedure gives ordered steps, a decision chooses between routes, a reference describes a resource, a format shapes the reply.
