A guide people can actually use

A permanent “How to use Unmute” section in the app, a smaller version inside the notch, and the same answers available from the Unmute Agent.

The idea

A new user should understand the shape of Unmute in about twenty seconds. The first screen is short. Everything else is there when they come back looking for a particular key or action.

A session does the work. The Unmute Agent helps you find and manage sessions.

Dictation

Puts the words you say into the app under your cursor.

Uses Fn or Right Option, depending on Settings.

Instruct

Changes selected text, or reshapes something you just said.

Press Caps Lock, say what to do, then press it again.

A session

One ongoing piece of work with its own conversation and context.

Speak directly to it with the session key.

The Unmute Agent

Finds and manages sessions, meetings, and things you asked Unmute to remember.

It is not the coding session doing the work.

Notetaker

Records a meeting and prepares its transcript and notes.

Double-tap Left Control to start or stop.

The pocket

Keeps sessions within reach without stopping them.

Hold Right Command first, then tap Right Option.

Where it lives

This is a core destination people can return to. It is not hidden in Settings and it is not another onboarding step.

Electron app

How to use Unmute is the first top-level sidebar item, above Dictation. It holds the full, glanceable guide.

The notch

A small Help button opens a temporary sheet with quick keys, this session, the pocket, meetings, and captures.

Unmute Agent

Ask “How do I…?” and the Agent looks up the same guide before answering.

What the full guide covers

1. The quick version

Dictation, Instruct, sessions, the Unmute Agent, and Notetaker in short rows.

2. Talking to a session

Start work, send a follow-up, leave it working, and return later.

3. The pocket

Collapse without stopping, move between cards, expand one, and understand Escape.

4. The Unmute Agent

When to use it, what it can find, and why it is different from a work session.

5. Meetings and captures

Start Notetaker, take meeting screenshots, and attach copied things while speaking.

6. Every shortcut

The complete reference, grouped by where and when each key works.

One guide, three ways to reach it

Why not one Markdown file?

Markdown is useful for review, but it cannot safely keep dynamic key settings, native notch rendering, and Agent search in sync by itself.

Where Markdown still helps

A readable Markdown reference is generated from the catalog. Humans can review it without creating another copy to maintain.

How the Agent uses it

A read-only Help tool searches the catalog. The core prompt carries only one short instruction to use Help for product questions.

What happens when Settings change

Fn and Right Option are resolved again, so every surface shows the keys the person actually uses.

Copy drift already exists

Agent help says to hold Right Command, while the keyboard state machine uses a double-tap to start. Settings says to hold the session key, while the state machine uses tap-toggle. A native comment says Notetaker stops with one tap, while the actual behavior requires two. This feature corrects the words to match the shipping behavior; it does not silently change the gestures.

How it should sound

Short, warm, and specific. No “routing,” “lanes,” “principals,” or implementation language. One useful example beats another paragraph.

Talk to this session

Tap Right Option, say what you want, then tap it again.

“Now add keyboard navigation.”

Can’t remember which session?

Ask the Unmute Agent. It can find the work and bring it back.

“Find the session where we changed Google login.”

Testing and scope

We will verify

  • The guide is the first top-level destination.
  • Configured keys update everywhere.
  • Notch Help closes before the session underneath.
  • Agent questions return the right guide entries.
  • Keyboard and session behavior does not regress.

Not part of this work

  • No onboarding step.
  • No new tour.
  • No keyboard behavior changes.
  • No hosted help center.
  • No analytics.
  • No autonomous Agent action from Help.
