Start and continue agent sessions

Start a session. Or pick one back up.

Press a key and speak to start a new agent session or send an instruction to an existing one. Ask a question, delegate a task, or give a follow-up — all from the app you're already using.

Capture context

Your thought comes with context. Bring it along.

The page you're reading. The error you're seeing. The design you want changed. Capture a link, text, or screenshot as you speak, and send it straight into your agent session.

Unmute Agent

Find the session. Remember the work.

Tell Unmute Agent what you want to return to. It finds the relevant agent session and brings back its context, including related conversations and meeting notes. Pick up the work without remembering where you left it.
