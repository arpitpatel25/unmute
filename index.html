// the second key — remote · a voice remote for Claude Code

Dictation types it. Remote does it.

Hold right ⌥, say the thing, it happens — on your actual Mac.

Here's the twist: unmute is dumb. Proudly, aggressively dumb. We didn't train a model — the smartest one already exists, you're already paying for it, and ours would only get in the way. We just gave it ears.

Which is the entire point. You already trust Claude Code — it's the best agent anyone has shipped. Remote is Claude Code: your own terminal session, just voice-driven. Nothing new to trust, nothing new to learn. Friendly neighborhood Claude Code.

And Claude Code can do, conservatively, anything. Most people use it for code, twice a day. Then Remote shows up and the list gets unhinged. Press a key, say it, done:

  • "who won the match last night?"
  • "put on the next episode."
  • "what's eating my battery — and kill it."
  • "rename these 40 screenshots by date."
  • "open Skyscanner, London to Tokyo, next Friday, cheapest."
  • "my flight's at 6 — when do I leave the house?"
  • "drop this tweet URL in my Google Sheet with a one-line summary."
  • "total every invoice in my Downloads and put it in a sheet."
  • "read this repo and tell me what it actually does."
  • "go through my last 50 emails and flag the 3 that actually need me."

None of these are features we built. It's just Claude Code, finally within reach. The bottleneck was never the model — it was the keyboard.

Two honest things: it needs a Claude Code Pro or Max plan, because it is one and it uses yours — that Max plan you open twice a day is about to earn its keep. // raw by default

We paste exactly what you said. No auto-punctuation, no autocorrect deciding you meant "ducking." Half of it's going into ChatGPT anyway, and ChatGPT has never once cared about your commas.
