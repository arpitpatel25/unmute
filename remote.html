— You're always the driver

Powerful, not unsupervised.

To get things done without nagging you about every step, Remote runs Claude Code with elevated permissions. Here's what keeps that safe.

Human-initiated, always

It only ever runs the one thing you asked, when you ask it. It is not an autonomous agent looping on its own.

Kill it instantly

Stop any task mid-run. Nothing keeps going in the background once you say stop.

Ask-before-acting, optional

Prefer a checkpoint? Turn on per-action approval, or sandbox it to a single folder.

Your credentials stay yours

unmute never handles your keys or logins. You authorize integrations in your own Claude Code, never through us.

— Setup

One thing, ~30 seconds.

  1. Install the Claude for Chrome extension from the Chrome Web Store.
  2. Keep one Chrome window open with the extension active.
  3. That's it — hold right ⌥ and start talking.

Everything else is optional. Add integrations like Gmail or Google Drive whenever you like — you authorize each one in your own Claude Code, in that same Chrome window. unmute never sees your credentials.
