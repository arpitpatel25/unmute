// the honest version

Most "AI agent" products hide what's under the hood. We won't: Remote is Claude Code, running on your machine. We didn't build a model. We built the part Anthropic didn't — a voice interface so good you forget there's a terminal involved.

Which means it needs a Claude Code Pro or Max plan (it uses yours). If that sentence lost you, Remote probably isn't for you yet — the dictation half still is.

// the point

You pay $100, $200 a month and reach for Claude Code maybe twice a day, for the "big" stuff. It can do almost anything on your computer. The reason you don't use it that way isn't the model — it's the friction of typing into a terminal.

Remote deletes the friction. You talk; it acts. The plan you already pay for, finally spent.

// how it works

  • 1. Speak the task. Hold right ⌥ and say it plainly. No prompt-craft, no syntax.
  • 2. It runs on your Mac. Your files, terminal, real logged-in Chrome, your apps. Not a sandbox.
  • 3. You watch, or don't. A live view shows what it's doing; an indicator flags "running" or "needs you."
  • 4. It comes back. Result lands where you're working — files and links you can click. Answer follow-ups by voice.

// you're the driver, not a passenger

To get things done without nagging you about every step, Remote runs with elevated permissions. The guardrails:

  • Human-initiated, always. It does the one thing you asked, when you ask. It is not an agent looping on its own.
  • Kill it instantly. Stop any task mid-run.
  • Ask-before-acting, optional. Turn on per-action approval, or sandbox it to one folder.
  • Your credentials stay yours. unmute never sees your keys or logins — you authorise things in your own Claude Code.

// setup, ~30 seconds

  • Install the Claude for Chrome extension.
  • Keep one Chrome window open with it active.
  • Hold right ⌥ and start talking. That's it.

Optional integrations (Gmail, Drive, …) are add-as-you-go, authorised in your own Claude Code. We never touch your credentials.
